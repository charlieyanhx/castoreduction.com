# Castor Foresight — where the tech goes, and where to stand

> We can't out-Manus Manus. The goal is to position where the puck is going, not
> where it is. This is an opinionated forecast of agentic-research tech and the
> defensible position it implies.

---

## The one law that governs everything

From Anthropic's own harness essay: *"every component in a harness encodes an
assumption about what the model can't do on its own — and those assumptions go stale
as models improve."*

**Corollary: anything that is just scaffolding around the model gets eaten by the
next model.** Browsing, planning, multi-step execution, the replay UI, "deep
research" — all of it converges into the frontier model + a browser within ~12-18
months. Manus, ChatGPT, Claude, Gemini all land in the same place. **Competing on
"a better autonomous research agent" means competing with the model labs. You lose.**

So the strategic question is only: **what does NOT commoditize as the model improves?**

---

## Predictions (with rough timing)

**P1 — The agent harness commoditizes (12-18 mo).** Autonomous browse→plan→synthesize→
artifact, plus the Manus-style replay UI, become base-model features or weekend clones.
Moat here ≈ 0. *(We literally specced the Manus UI in an afternoon.)*

**P2 — Reproducibility becomes the enterprise battleground (now → 24 mo).** We measured
Manus swinging **TAM 47% and SOM 27× on the identical prompt across two runs**. As
agents flood every desk, "two runs, two answers" becomes the #1 objection for any
output that drives a decision. Determinism + sourcing + reproducibility get *more*
valuable precisely as generation gets cheaper: everyone can produce a plausible report;
almost no one can produce a *defensible, repeatable* one.

**P3 — Provenance/verifiability goes from nice-to-have to required (18-36 mo).** When AI
outputs move money (lending, underwriting, M&A, audit), "show every source and the
math" becomes a compliance line, the way it already is for financial advice. First mover
on **audit-grade provenance** owns the regulated segment.

**P4 — The open web degrades as a data source (now, accelerating).** AI slop, paywalls,
and bot-blocking poison scraping (we hit WAF blocks live this session). Value migrates to
**authoritative + proprietary feeds** — Census/BLS/filings, plus real-time signals
(transactions, foot-traffic, hiring, ad spend). Scrape-reliant agents degrade; data-wired
ones compound.

**P5 — Vertical agents beat horizontal (12-24 mo).** Manus is horizontal ("do anything").
Winners own a domain's workflow + data + liability. Horizontal general agents become the
*substrate*, not the product. "Market research for capital decisions" is a vertical.

**P6 — The artifact stops being a report (24-48 mo).** A static PDF is a 20th-century
output. The future is a **living, queryable market model** that updates itself
(monitoring/Scheduled) and that you interrogate. Whoever becomes the *system of record*
for a venture's market truth wins retention; whoever ships PDFs churns.

**P7 — Agents transact, not just inform (24-48 mo).** The endgame isn't "your idea is
viable" — it's the agent routing you to capital, pre-filling the application, and closing.
**Research → action → money.** This is exactly the Castor business arc (research wedge,
capital marketplace anchor).

**P8 — Trust shifts to attestation (36 mo+).** When anyone can generate anything, the
scarce asset is *who vouches for it*. Independent-judge + deterministic-gate +
auditable-trail is proto-attestation — the seed of a "verified by" standard.

## What commoditizes vs. what compounds

| Commoditizes (don't build moat here) | Compounds (build here) |
|---|---|
| Autonomous browse/plan/synthesize | **Reproducible, deterministic numbers** |
| Replay UI / chat UX / "deep research" | **Audit-grade provenance + validation** |
| General web research | **Authoritative + proprietary data wiring** |
| Prettier reports | **The living, monitored market model** |
| Being horizontal | **Owning the capital-decision vertical** |
| Informing | **Transacting (research → capital)** |

## Where Castor stands (skate-to-the-puck)

**Not** "an AI that writes market research." **Yes:** *the verification-and-action
layer for new-business decisions* — the place where a market claim becomes
**defensible, reproducible, sourced, and connected to capital.**

The defensible stack, top to bottom:
1. **Capital/action loop** — route the founder to funding, pre-fill, close. (network + liability)
2. **Living market model** — continuously updated, queryable, monitored. (retention + data flywheel)
3. **Audit-grade numbers** — every figure sourced, reconciled, gated, reproducible. (the moat that *grows* as agents commoditize)
4. **Authoritative + proprietary data** — Census/BLS/filings + real-time signals. (input moat)
5. *(substrate)* the harness/agents — commodity; use the best available, don't over-invest.

Read top-down, that's a company. Read bottom-up, it's why no model lab and no horizontal
agent will casually take it: they optimize the substrate (layer 5); the value is layers 1-4.

---

## The concrete bets (what to do now, that positions ahead)

1. **Make reproducibility + audit-grade provenance the BRAND**, not a feature. "Underwriting-
   grade market intelligence — every number sourced, every run repeatable." This is the one
   axis that *appreciates* as generation commoditizes (P2/P3). Lean in hardest here.
2. **Ship the living market model, not the PDF.** Prioritize Scheduled/monitoring as the
   product spine (P6). The report is a snapshot of a model that keeps updating.
3. **Wire proprietary/authoritative data as the input moat** (P4): finish Census/BLS, add
   filings, foot-traffic, hiring, ad-spend. The numbers chain is only as strong as its
   softest input (audit M2) — own the inputs.
4. **Own the research→capital transaction** (P7) — the marketplace is the endgame, not a
   bolt-on. Agents that move money beat agents that summarize.
5. **Treat the UI/harness as commodity** — clone Manus's UX fast and cheaply (the teardown
   is done), then stop. Don't sink quarters into scaffolding the model will absorb (P1).
6. **Start the attestation play** (P8): the independent-judge + deterministic-gate + signed
   audit trail is the seed of a "Castor-verified" mark. Make the trail exportable/shareable.

## The threats (be honest)

- **Model labs verticalize down** — Anthropic/OpenAI/Google add native "research + cite."
  Defense: data wiring + capital network + liability they won't touch.
- **Data incumbents agentify up** — CB Insights/Bloomberg/PitchBook bolt on agents over
  their proprietary data. Defense: the underserved *new-business / SMB* segment they ignore,
  + the capital-action loop they don't own.
- **Our own window is the gap between those two.** Own the verification+capital layer for
  new businesses before either side reaches it. That window is ~18-36 months.

---

## One line
The harness is the wave everyone's surfing; it commoditizes. **Castor's bet is the three
things that get *more* scarce as agents get cheaper: reproducible truth, verifiable
provenance, and a direct line to capital.** Build there; rent the rest.

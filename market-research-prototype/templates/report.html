Methodology Appendix

Pipeline. This report is produced by a multi-step market research pipeline following the Castor Advisories Market Research Spec. Each step either extracts structured data, runs a deterministic calculation, or performs a simulated research exercise via LLM. {{ steps_completed|length }} steps completed for this run.

Competitor discovery (spec 3a-3d). LLM-generated search queries surface candidate brands. Each candidate is scored on traffic momentum, Trustpilot velocity, Instagram followers, and Wayback-Machine activity. Parked domains and megabrand contamination are filtered out. Top candidates feed clustering.

Clustering + projection (spec 3c). Method: {{ clustering.method if clustering else 'tfidf + kmeans + pca' }}. Semantic embeddings (BAAI/bge-small-en-v1.5, 384-dim, ONNX) with TF-IDF fallback. HDBSCAN for density-based clustering with K-Means fallback; UMAP for 2D projection with PCA fallback. {% if clustering and clustering.silhouette_score %}Silhouette score: {{ clustering.silhouette_score }}.{% endif %} {% if clustering and clustering.noise_count %}Noise points (don't fit any cluster): {{ clustering.noise_count }}.{% endif %} PCA/UMAP axes are LLM-interpreted from cluster extremes.

Differentiators (spec 3d). Single LLM call cross-references our features against cluster members to identify features no cluster has. Null result ("no differentiators found") is treated as a critical finding, not a failure.
